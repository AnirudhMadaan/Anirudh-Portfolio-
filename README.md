# Anirudh — Cosmic 3D Portfolio Upgrade

This version keeps the original portfolio content and upgrades the visual system with a more cinematic, glassmorphism-inspired cosmic interface.

## Page-specific 3D scenes
- Home — interactive wireframe planet hero
- About — Mars-inspired 3D planet
- Resume — Saturn-inspired planet with rings and orbiting moons
- Skills — futuristic neural/tech core with rotating rings
- Projects — cratered Moon with an orbiting satellite
- Contact — animated black hole with an accretion disk and jets

## Run
Open `index.html` in a modern browser. Three.js is loaded from cdnjs, so an internet connection is recommended for the 3D scenes. The existing CSS/JS fallback behavior remains in place for the background.

## Main upgrade files
- `assets/css/style.css` — upgraded visual system and responsive layout
- `assets/js/celestial-scenes.js` — procedural 3D scenes for inner pages
- `assets/js/hero-planet.js` — existing interactive home hero
