# 👋 Anirudh's Portfolio

Welcome to my personal portfolio website! 🚀

This project is a place where I showcase who I am, what I'm learning, and the projects I build along the way.

I'm currently a **Computer Science and Engineering student** and actively learning web development and programming. Instead of using a ready-made template or website builder, I built this portfolio using core web technologies and improved it step by step as I learned new concepts.

## 🌐 Live Demo

The portfolio is deployed and live on Netlify.

🚀 **Live Website:** https://anirudhmadaan.netlify.app

Check out the website to explore my skills, projects, resume, and contact information.

## 🚀 What's Inside

The portfolio includes several sections:

* 🏠 **Home** — A quick introduction and overview
* 👨‍💻 **About** — More about me and my journey
* 📄 **Resume** — Education, skills, certifications, and experience
* 🛠️ **Skills** — Technologies and tools I'm learning

## 🧰 Technologies Used

This project was built using:

* **HTML5** — Website structure
* **CSS3** — Styling, animations, layouts, and responsive design
* **JavaScript** — Interactive features and animations
* **Formspree** — Contact form handling

No frameworks or heavy libraries were used. The project is built mainly with **vanilla HTML, CSS, and JavaScript**.

## ▶️ How to Run Locally

You can run this project without installing anything.

### Option 1: Open Directly

Download or clone the repository and open:

```text
index.html
```

in your browser.

### Option 2: Use a Local Server

If you have Node.js installed, run:

```bash
npx serve .
```

Then open the local address shown in your terminal.
