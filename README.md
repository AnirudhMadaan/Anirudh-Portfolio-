# Anirudh Portfolio (Improved)

An enhanced version of the original portfolio with the same dark purple cosmic theme.

## What's new

- Rich home page with typing animation, stats, and preview sections
- Mobile hamburger navigation
- Back-to-top button and extended scroll-reveal animations
- Improved accessibility (skip link, ARIA labels)
- Polished About, Skills, Projects, Resume, and Contact pages

## Open locally

Open `index.html` in your browser, or use a local server:

```bash
npx serve .
```
